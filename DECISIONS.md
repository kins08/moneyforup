# DECISIONS — решения, принятые в ходе редизайна

## D1. XP заменяется на токены (⬦) везде
Прогрессия и награды только в токенах. В коде XP-механики не было, замена касается только плана (`So.txt`, этапы 2 и 6).

## D2. Live Arena удаляется
Решение пользователя. Этап 6 не содержит Live Arena. Ботов и «соревнования» нет.

## D3. Игры — ставки из баланса, без бесплатных токенов
- Pulse Market и Trend Hunter: игрок ставит токены, которые уже есть на балансе. Выплата = ставка × множитель. Ставка списывается атомарно на сервере.
- Бесплатных начислений токенов в этапах 2, 3, 6 нет.
- Выплаты всегда меньше вероятности выигрыша (house edge > 0). Касса в плюсе.

## D4. Апгрейдер: без режимов, потолок шанса 70%
- Пользователь: «не нужны режимы, они перегружают интерфейс». Режимы SAFE / BALANCED / EXTREME и их названия полностью убираются из UI. В API остаётся один внутренний набор параметров (id `standard`).
- Параметры: комиссия (edge) 6%, потолок шанса 70%, максимальная цель ×100, минимальная цель +5% к источнику.
- Шанс = min(70%, (1 − edge) × источник / цель). Шанс ниже 70% для любой цели, которая дороже источника.
- Старые id режимов (`safe`, `balanced`, `extreme`) сервер принимает и маппит в `standard`, чтобы не ломать закэшированные клиенты.
- Шанс и результат считает только сервер. Анимация прокрутки стартует по нажатию и останавливается на результате, который вернул сервер. Цвет остановки совпадает с результатом: зелёный для выигрыша, красный для проигрыша.
- Этот пункт меняет финансовое правило (потолок шанса с 90/75/40% до 70%). Пользователь подтвердил его вопросом-ответом.

## D5. Pulse Market: крипто-рынок, ставка на направление
- Раунды 5, 10, 20 с. Направления: вверх, вниз, боковой диапазон.
- Исход определяется на сервере: HMAC(серверный секрет, roundId). Клиент получает результат только после окончания раунда.
- Механики трейдинга: выбор направления, плечо (×1 / ×2), стоп-выход. Выплата и вероятность заданы в одной таблице кода.
- Раунд хранится в существующей таблице `game_rounds` (game = 'pulse'). Новых таблиц и миграций нет.

## D6. Trend Hunter: распознавание паттернов
- Паттерны: рост, падение, боковик. 3 уровня сложности.
- Ставка из баланса, ответ «правильно/неправильно». Множитель зависит от сложности и фиксирован в коде.
- Правильный ответ и сложность задаются на сервере при генерации сценария и не меняются после ответа.
- Комбо-счётчик только отображается: выплата не зависит от серии. Так экономика не получает скрытых бонусов.
- Раунды хранятся в `game_rounds` (game = 'trend').

## D7. Хранение без миграций
- Схема БД не меняется. Новые данные идут в `game_rounds`.
- Статистика игрока (точность, лучший результат, любимый режим) вычисляется из `game_rounds` на сервере.
- Ежедневные миссии вычисляются из `game_rounds` за текущие сутки. Таблица миссий не нужна.

## D8. Прогрессия: только косметика и титулы
- Daily Missions, Collection Book, сезонный прогресс: награды — рамки, цвета темы, титулы, значки в профиле.
- Выбранная косметика хранится в `localStorage` клиента. Она не влияет на баланс, поэтому серверного хранения не нужно.
- Market Replay: просмотр своих последних раундов Pulse Market.
